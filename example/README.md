# Kitsumon Examples

This folder contains usage examples demonstrating how to use the `kitsumon` package to query the [Kitsu.io](https://kitsu.io) API.

## Available Examples

- `kitsumon_example.dart`: Basic initialization and fetching anime character collections and resources.
- `kitsumon_anime_example.dart`: Fetching anime collections with filters, includes, and sorting.
- `kitsumon_anime_characters_example.dart`: Querying anime characters by role and anime ID.

## Running an example

Run any example using the Dart CLI:

```bash
dart run example/kitsumon_example.dart
```
